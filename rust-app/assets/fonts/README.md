# Pantry Label fonts (normal Latin subsets)

Unmodified Google Fonts assets, retrieved2026-10-13. Young Serif400 and Atkinson
Hyperlegible Next variable200–800 cover the auth UI's regular/bold English text.
Other scripts or italic text may fall back; these are not complete font families.
